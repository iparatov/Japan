# Путеводитель «Япония · 30.10–09.11»

Офлайн-приложение для двух iPhone. Всё приложение — папка `dist/`.

## Как опубликовать (один раз, ~5 минут)

**Netlify Drop — самый простой путь**

1. Откройте https://app.netlify.com/drop и войдите (подойдёт аккаунт GitHub или почта).
2. Перетащите в окно папку `dist` целиком.
3. Через несколько секунд появится адрес вида `https://случайное-имя.netlify.app`.
4. В настройках сайта (Site configuration → Change site name) можно задать своё имя.

**GitHub Pages — если удобнее GitHub**

1. Новый репозиторий → Add file → Upload files → перетащить содержимое `dist`.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Адрес: `https://<логин>.github.io/<репозиторий>/`.

## Как поставить на iPhone

1. Открыть адрес в **Safari** (не в Telegram и не в Chrome) — при хорошем интернете.
2. Подождать, пока откроется маршрут.
3. «Поделиться» → «На экран Домой» → «Добавить».
4. Открыть с иконки один раз при интернете — после этого всё работает без сети.

Сделать на обоих телефонах. Отметки, курс и вишлист хранятся на каждом телефоне отдельно.

## Как обновить данные

1. Поправить таблицу «Поездка Япония Ноябрь».
2. Попросить Claude пересобрать (`python3 build.py`) — он скачает таблицу и соберёт новую `dist/`.
3. Перезалить папку `dist` тем же способом (в Netlify: Deploys → перетащить папку ещё раз).
4. На телефоне открыть приложение при интернете, закрыть и открыть снова — подтянется новая версия.
   Отметки «Сделано» и «Куплено» при этом сохраняются.

## Что внутри

- `build.py` — сборка: прототип Claude Design (`src/prototype.html`) + таблица (`src/table.xlsx`) → `dist/`.
- `src/copy.json` — человеческие тексты: «как в таблице → как в приложении». Новые тексты из таблицы,
  которых тут нет, попадают в `report.md`.
- `report.md` — что сборка заметила: убранные и новые пункты, тексты без перевода на человеческий.
- `tests/` — проверки: `python3 -m unittest tests/test_build.py` и `node tests/e2e.mjs dist/index.html`.
